Verified Ephemeral Encryption

Exchange handshake text, then compare the complete safety code through an independent trusted channel, such as an in-person conversation. Both people must verify before exchanging encrypted messages.

Keys stay in this page's memory. Refreshing, leaving, ending, or changing a session permanently loses access to its messages. Sessions expire one hour after generating your handshake; switching tabs is safe.

P-256 · HKDF-SHA-256 · AES-256-GCM. This custom protocol has not received an independent security audit or certification and is not post-quantum secure. Security and deployment guide

Session: Not generated · Expires: —

1. Exchange handshakes

Use one new handshake per session. Changing the other person's handshake ends the current session. Old v1 messages and JWK key exports are not supported.

2. Verify the complete safety code

Contact the person through a separate channel you already trust. Compare every group, in order. A matching code identifies this session only. If any character differs, end the session.

3. Exchange encrypted messages

Maximum: 1 MiB of UTF-8 plaintext per message; 65,536 messages and 64 MiB per direction in a session. Messages may arrive out of order within the latest 128 sequence positions. Duplicate or older messages are rejected. A failed decryption clears the plaintext field.
